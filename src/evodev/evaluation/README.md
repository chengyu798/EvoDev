# 运行评测

本目录保存确定性评测模型与逻辑，汇总测试是否通过、Patch 规模、重试次数、耗时和
Token 用量。任务成功必须以真实测试证据为基础，不能仅依赖 LLM 评审结论。

- `models.py`：定义最终评测指标结构。
- `costs.py`：根据配置单价估算修复运行费用，保留币种与价格依据；未知单价不计为零。
- `comparison.py`：冻结样例、Prompt 和经验快照，执行可审计的经验对照实验；默认仅预检，
  显式传入 `--execute` 才会调用模型。
- `experiences.py`：从失败状态提炼 Experience，并生成可解释的检索标签。
- `retrieval.py`：按标签类别和历史质量计算匹配分，并过滤低相关经验。
