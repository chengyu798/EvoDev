# Agent 工具层

本目录定义向 Agent 暴露的受控仓库工具，包括文件列表、读取、搜索、Patch 应用和
Git Diff。所有路径都应限制在当前任务工作区内，工具调用应能被运行轨迹记录。

- `RepositoryTools`：列出普通文件、读取 UTF-8 文本和按行搜索文本。
- `EditTools`：使用 `git apply --check` 校验补丁后再执行修改。
- `GitTools`：查询基准提交和变更文件，并生成包含新增文件的 Diff 与 Patch。
- `paths`：拒绝绝对路径、路径跳转和指向工作区外部的符号链接。

文件和补丁均有大小限制，仓库读取不会返回 `.git` 元数据或符号链接。
