# 执行时基础设施

本目录负责任务工作区、命令执行和 Docker 沙箱。所有可能修改仓库或执行用户代码的操作
都应有工作目录边界、超时、输出上限和明确的失败结果，不得直接修改原始仓库。

`WorkspaceManager` 负责在专用根目录中生成安全路径、创建空工作区、检查工作区是否存在
以及清理运行结束后的目录。运行标识不能包含路径分隔符或路径跳转字符，创建操作也不会
覆盖已有目录。`prepare_repository` 会创建独立 Git 克隆并切换到指定提交，工作区修改
不会影响源仓库。

`DockerCommandRunner` 使用参数列表执行命令，不启用 Shell。容器默认关闭网络、删除全部
Linux Capability、启用只读根文件系统，并限制 CPU、内存和进程数量。命令结果统一记录
退出码、耗时、标准输出、错误输出、超时和输出截断状态；超时后会强制清理容器。

`PytestRunner` 只接受 pytest 命令，在 Docker 沙箱中执行基线或修复后测试，并通过真实
退出码与超时状态判断测试是否通过。
