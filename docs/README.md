# 文档目录

本目录保存项目方案、任务清单、架构决策和多智能体闭环说明。正式项目文档按
`NN-简单中文名称.md` 连续编号，例如 `03-接口设计.md`。

`README.md` 仅用于说明目录职责，是编号规则的例外，不占用正式文档序号。

- `00-EvoDev_多智能体自进化软件开发系统方案.md`：最初的项目方案和目标。
- `01-一周开发任务清单.md`：每日任务、范围约束和最终验收项。
- `02-系统架构设计.md`：总体架构、LangGraph Mermaid 运行图和数据模型。
- `03-多智能体闭环说明.md`：Agent 职责、模型配置、运行产物和命令行执行方式。
- `04-手动测试指南.md`：带真实截图的完整手动测试、运行证据检查和环境清理步骤。
- `05-经验进化说明.md`：说明失败经验的生成、存储、检索、注入和验证方式。
- `06-自进化机制说明.md`：说明经验效果学习和异步 Prompt 进化、评测、升级与回滚。
